A — Wider Column

Bump max-width from 900px to ~1200px. Same vertical stack layout, just more breathing room. Increase font sizes slightly (body 15-16px instead of 14px). Simplest change.

Pros

  • Minimal code changes
  • Keeps the focused, clean feel
  • Scales down gracefully

Cons

  • Still wastes space on ultrawide
  • Long text lines can hurt readability beyond ~75ch

B — Paired Sections (Recommended)

Widen to ~1400px and pair complementary sections side-by-side on wide screens: About + Projects, Work + Certs. Hero goes full-width. On narrower screens, sections unstack to single column. Bigger fonts throughout.

Pros

  • Uses screen real estate purposefully
  • Natural content pairings
  • Feels like a dashboard, not a document
  • Collapses cleanly to mobile

Cons

  • More layout changes needed
  • Sections must work at half-width

C — Full Dashboard

Centered hero, then all sections laid out in a flexible bento-style grid. Every section becomes a card in the grid. Most dramatic visual change — feels like a personal dashboard rather than a scrolling page.

Pros

  • Maximum use of space
  • Visually distinctive
  • Everything visible at a glance

Cons

  • Biggest rewrite
  • Harder to make responsive
  • Work section needs heavy restructuring
  • Less conventional — may confuse some visitors
